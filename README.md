COVID-19 Data Visualization with Power BI
This project uses Power BI to visualize and analyze global COVID-19 data from the covid_19_data.csv file. The dataset includes information about countries and their states/regions, showing the number of confirmed cases, deaths, and recoveries.

Key Features:

🗺️ Interactive map showing country-wise spread of COVID-19

📈 Trend analysis of confirmed, death, and recovery cases

📊 Visual breakdown by country and state

📅 Timeline-based insights into the progression of the pandemic

🔍 Filters and slicers for dynamic data exploration

## Questions for COVID-19 Dashboard
1. Which country/region has the highest total number of confirmed cases?

2. What is the total number of deaths recorded globally?

3. Which province/state has the highest number of deaths?

4. What is the total number of recovered cases globally?

5. Which province/state shows the highest recovery count?

6. How do confirmed cases compare across countries/regions?

7. What is the death rate by province/state (deaths vs. confirmed cases)?

8. What is the recovery rate by province/state (recovered vs. confirmed cases)?

9. Which country shows the fastest growth in confirmed cases over time?

10. Which regions have zero or very low death counts despite high confirmed cases?

## Project Process Overview
Data Import: Loaded covid_19_data.csv into Power BI.

Data Cleaning: Removed nulls, standardized columns, and formatted date fields.

Data Modeling: Created relationships and calculated fields using DAX.

Visualization: Built interactive charts, maps, and KPIs to show confirmed, deaths, and recovered cases by country and state.

Insights: Analyzed trends, compared regions, and highlighted key metrics.
